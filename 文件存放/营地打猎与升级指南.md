# CDDA-Breeze 营地：打猎产出与营地升级完全指南

> 本文所有结论均基于本仓库源码实测推导，关键处标注了 `文件:行号`，可自行复核。
> 适用版本：本 fork（CDDA-Breeze，0.G 系代码基）。

---

## 0. 结论速览

| 问题 | 结论 |
|---|---|
| "可能产出不能覆盖消耗的食物"是真实预测吗？ | **不是**。它是写死在 `src/faction_camp.cpp:1205` 的一句文案，对每个营地、每个同伴都一模一样，不读取任何数值。 |
| 打猎实际赚不赚？ | **期望上是赚的**，而且赚得不少（估算 1 名猎人 ~2 万 kcal/天，吃掉 2500 kcal/天）。真正的瓶颈不在概率，而在 **屠宰 + 保鲜**。 |
| 打猎产出由什么决定？ | 只由 **执行同伴的枪法(gun) 与感知(PER)**、以及 **外出时长** 决定。营地建筑、等级、装备**完全不影响**。 |
| 打猎能派几个人？ | **1 个**（`Positions: %d/1`，`faction_camp.cpp:1208`）。陷阱 2 个，采集 3 个。 |
| 营地怎么升级？ | 三套机制并存：**老式等级链**（legacy）、**中心/扩张地块蓝图建造**（主流）、**新增扩张地块**（Expand Base）。 |

## 1. 打猎任务到底怎么算

### 1.1 那句"警告"的出处

```cpp
// src/faction_camp.cpp:1196-1208
if( has_provides( "hunting", dir ) ) {
    ...
    entry = string_format( _( "Notes:\n"
        "Send a companion to hunt large animals.\n\n"
        "Skill used: marksmanship\n"
        "Difficulty: N/A\n"
        "Hunting Possibilities:\n"
        "> small, medium, or large animal corpses\n"
        "May produce less food than consumed!\n"      // ← 写死的
        "Risk: Medium\n"
        "Time: 6 Hours, Repeated\n"
        "Positions: %d/1\n" ), npc_list.size() );
```

陷阱任务（`faction_camp.cpp:1182`）也写着同一句。所以 **看到这句话不代表这次会亏**，它只是"提示你别指望靠打猎养活全营"的定性提醒。

### 1.2 产出公式（真实逻辑）

出发：`faction_camp.cpp:1846-1852`，结算：`faction_camp.cpp:3602-3676` 与 `4305-4355`。

```
① 判定次数 attempts = checks_per_cycle × (实际外出时长 / min_time)
     打猎 Camp_Hunting: checks_per_cycle = 2, min_time = 6 小时
     → 每 6 小时 2 次判定；外出 24 小时 = 8 次判定

② 单次成功率：skill > rng(0, 30)
     skill = 1.5 × 枪法等级(gun) + 感知(per_cur) / 2     【向下取整】
     rng(0,30) 含端点，共 31 个取值
     → 单次成功率 p = skill / 31

③ 成功一次 = 按权重表随机抽 1 具尸体（item::make_corpse）
```

**成功率对照表**（`p = floor(1.5×枪法 + 感知/2) / 31`）：

| 枪法 | 感知 | skill | 单次成功率 | 24h 判定次数 | 期望尸体/天 |
|---|---|---|---|---|---|
| 0 | 8 | 4 | 13% | 8 | 1.0 |
| 2 | 8 | 7 | 23% | 8 | 1.8 |
| 3 | 10 | 9 | 29% | 8 | 2.3 |
| 5 | 10 | 12 | 39% | 8 | 3.1 |
| 8 | 12 | 18 | 58% | 8 | 4.6 |
| 10 | 14 | 22 | 71% | 8 | 5.7 |

**注意两个反直觉的点：**

1. 感知只算一半，枪法权重是感知的 3 倍 → **优先挑枪法高的，其次才是感知**。
2. `per_cur` 是**当前**感知，同伴疲劳、状态异常、用药都会拉低它 → 让猎人休息好再派。

### 1.3 猎物权重表与产肉估算

`faction_camp.cpp:4308-4345`。打猎权重表（总权重 136）：

| 猎物 | 权重 | 体重 | 生肉热量估算¹ |
|---|---|---|---|
| 鸡 | 20 | 3.5 kg | ~1,300 kcal |
| 郊狼 | 15 | 13.3 kg | ~3,700 kcal |
| 狼 | 10 | 26.6 kg | ~7,500 kcal |
| 火鸡 | 10 | 8 kg | ~2,300 kcal |
| 水獬 / 河狸 | 10 / 10 | 9 / 20 kg | ~2,400 / ~5,600 kcal |
| 红狐 / 灰狐 | 10 / 10 | 4.1 kg | ~1,200 kcal |
| 鸭 | 10 | 1.5 kg | ~800 kcal |
| 海狸鼠 / 貂 | 10 / 5 | 1.4 / 0.8 kg | ~400 / ~400 kcal |
| 美洲狮 | 5 | 63 kg | ~17,900 kcal |
| 鹿 | 2 | 87 kg | ~26,300 kcal |
| 熊 / 猪 / 驼鹿 / 牛 | 各 1 | 154 / 200 / 386 / 680 kg | 4.4 万 / 6.1 万 / 11.7 万 / 20.7 万 kcal |

¹ 估算依据：屠宰产出 = `体重 × mass_ratio(0.28~0.32) × 产出系数(约 0.7)`，再按肉块 296 g / 402 kcal 折算，见 `activity_handlers.cpp:794-802, 904-906, 1021-1024`。

- **期望值**：每具尸体 ≈ **6,300 kcal**（被牛/驼鹿/熊这些权重 1 的稀有大型猎物严重拉高）。
- **中位数**：≈ **1,300 kcal**（约一半的猎物连 1,500 kcal 都不到）。
- 结论：打猎是 **高方差** 收益 —— 大部分时候是小动物，偶尔一发入魂直接爆仓。

### 1.4 食物消耗公式

```cpp
// faction_camp.cpp:5135-5138
int time_to_food( time_duration work ) { return 2500 * to_hours<int>( work ) / 24; }
// faction_camp.cpp:5113-5128  派系 food_supply 单位就是 kcal
// 显示"还能撑几天" = food_supply / 2500
```

- **1 名同伴 1 天消耗 2500 kcal 营地储备**（≈104 kcal/小时）。
- 出发时先扣 `time_to_food(6h)=625`，召回时再补扣 `time_to_food(实际时长 - 6h)`（`faction_camp.cpp:3431`）。
- 储备不足会直接拒绝派人：`"You don't have enough food stored to feed your companion."`（`faction_camp.cpp:1920`）。

**关键点：产出与消耗都随外出时长线性增长**，所以"让他多待几天"**不会**改变产肉/耗粮比，只会把总量放大（并累积风险）。

### 1.5 风险事件（同伴会死）

```cpp
// faction_camp.cpp:3638
if( one_in( danger ) && !survive_random_encounter( *comp, task_description, favor, threat ) )
```
- 打猎 `danger = 10`（**每次召回 1/10 概率触发**），`favor = 0`，`threat = 12`。
- 判定顺序（`faction_camp.cpp:5445-5495`）：
  1. 生存技能 + favor > rng(0,10) → 溜走，练 gathering；
  2. 口才 + favor > rng(0,10) → 友好的路人，练 recruiting；
  3. 前两项都失败 → 战斗判定：`(近战 + 0.5×生存 + 钝击 + 斩击 + 刺击 + 徒手 + 闪避) × rng(8,12) > 怪物数 × rng(8,12)`；
  4. **失败 = 同伴死亡**（`place_corpse`，从 overmap 移除）。

> 也就是说：打猎的死伤概率约 10%，且**打猎技能本身不参与自保判定**。
> 想保人，就派**生存和口才高**的（两次逃脱机会），而不是只堆枪法。

### 1.6 真正的瓶颈：屠宰与保鲜

打猎带回的是**整具尸体**，不是肉。要变成食物还得走你自己的流程：

1. **屠宰产出系数**（`activity_handlers.cpp:794-802`）：
   ```
   yield = 0.5 × clamp(生存/10, 0, 1) + 0.3 × clamp((工具品质+50)/100, 0, 1) + 0.2 × clamp(敏捷/20, 0, 1)
   ```
   生存 0、敏捷 8、无工具 ≈ **0.34**；生存 10、敏捷 12、好刀 ≈ **0.68**。
   **差距接近 2 倍**，这是玩家侧最大的可控杠杆。
2. **工具品质**：用 `BUTCHER` 品质高的刀（切肉刀/屠刀 > 小刀）。
3. **流程损耗**：开膛去内脏（FIELD_DRESS）扣 25%、剥皮扣 15%、尸体被打烂（GIBBED）额外扣 15%（`activity_handlers.cpp:850-862, 1098-1114`）。
4. **保鲜**：生肉 `spoils_in: 1 day`（`data/json/items/comestibles/carnivore.json:222`）。
   一堆肉 1 天就烂 —— 必须**熏制/腌制/冷冻**。营地建 **熏制房（smoking）** 和 **储藏室（pantry）** 就是为这个。

## 2. 怎么提升打猎质量（按性价比排序）

### ① 选对猎人：枪法 > 感知（唯一影响概率的因素）
- 枪法每 +1，skill +1.5；感知每 +2，skill 才 +1。
- 优先派 **NC_HUNTER / 赏金猎人 / 士兵类** 同伴，或你自己练起来的高枪法 NPC。
- 派之前确认他 **不疲劳、无降感知的状态**（`per_cur` 会掉）。

### ② 让他在外面多待（放大总量，不改比率）
- 任务标记是 `Repeated`，不召回就一直打。每 6 小时 +2 次判定。
- 适合"营地不缺粮、想囤肉"的场景；缺粮时别这么干。

### ③ 提高屠宰产出（收益最大的玩家侧操作）
- 练自己的 **生存技能**（权重 0.5）和 **敏捷**（权重 0.2）。
- 用高 `BUTCHER` 品质刀具。
- 走完整流程：放血 → 剥皮 → 开膛 → 分割（不要一键"快速屠宰"，`QUICK` 会让肉 `/4`）。

### ④ 陷阱 vs 打猎：陷阱其实更高效

| | 打猎 | 陷阱 |
|---|---|---|
| 判定次数 | 2 次 / 6h（1 人） | **4 次 / 6h × 2 人 = 8 次** |
| 技能公式 | `1.5×枪法 + 感知/2` | **`2×陷阱 + 感知`** |
| 典型成功率（技能 5、感知 10） | 39% | **65%** |
| 猎物 | 含大型（鹿/驼鹿/牛） | 只有小/微型（鼠/花栗鼠/兔…） |
| 期望热量/具 | ~6,300 kcal（高方差） | ~890 kcal（稳定但小） |
| 危险 | 1/10 | 1/15 |

→ **前期缺稳定口粮：用陷阱**（判定多、成功率高、2 个位置）。
→ **中后期要爆发：用打猎**（赌大型猎物）+ 陷阱保底，两条线一起跑。

### ⑤ 降低死亡风险
派 **生存 ≥ 5** 或 **口才 ≥ 5** 的同伴去打猎 —— 这两项能让他直接躲过遭遇战，而枪法不能。

### ⑥ 代码层面的坑（维护者注意）
打猎结算时训练的技能组是 `"hunting"`（`faction_camp.cpp:3631`），而 `data/json/skills.json` 里 **没有 `hunting` 这个技能 id**，它是一组训练标签，映射到：

| 技能 | hunting 训练权重 |
|---|---|
| archery（弓术） | 45 |
| rifle（步枪） | 45 |
| pistol / shotgun / smg | 各 25 |
| survival | 15 |
| dodge | 15 |
| bashing / cutting / stabbing / unarmed / melee | 各 10 |

**但打猎判定的技能是 `skill_gun`（marksmanship，枪法），它的训练权重表里只有 `gathering:60 / combat:5`，没有 `hunting`。**

→ 也就是说：**反复派出去打猎，练的是弓术/步枪/手枪，不是枪法，成功率不会随经验提升。** 这是原版遗留的设计错位。

如果你想修（三选一，都在 `src/faction_camp.cpp`）：
- **A（推荐）**：`3632` 行改成用 `skill_rifle` 或 `skill_archery`，与训练目标对齐；
- **B**：`data/json/skills.json` 给 `gun` 的 `companion_skill_practice` 加一条 `{ "skill": "hunting", "weight": 45 }`；
- **C**：`3632` 行改成 `1.5 * (枪法 + 步枪) / 2 + 感知/2`，兼顾两条线。

## 3. 营地怎么升级

营地有三套"升级"机制并存，容易混淆：

### 3.1 三套机制

| 机制 | 说明 | 代码位置 |
|---|---|---|
| **A. 蓝图建造（主流）** | 布告栏里按方向分标签页，列出可建蓝图，派人施工，建成后 `blueprint_provides` 解锁新功能/新任务 | `basecamp.cpp:301-360` |
| **B. 新增扩张地块** | 在营地向周围 8 格扩张出新地块（农场/铁匠铺/前哨…），每个地块有自己的蓝图树 | `faction_camp.cpp:4122-4187` |
| **C. 老式等级链** | `faction_base_<type>_0/1/2...` 的线性升级，仅用于兼容旧存档 | `basecamp.cpp:102-113, 238-259` |

现在正常玩只需要关心 **A + B**。

### 3.2 布告栏界面

在营地放置/使用**公告板（Bulletin Board）**打开营地管理器：

- 顶部标签页：`MAIN`（中心地块）、`[N]` `[NE]` `[E]` `[SE]` `[S]` `[SW]` `[W]` `[NW]`（各扩张地块），
  定义在 `basecamp.cpp:47-58`。
- `MAIN` 页里有：分发食物（Distribute Food）、**扩张基地（Expand Base）**、分配工作、分配岗位、紧急召回、放弃营地。
- 每个方向页里：该地块的**可建蓝图列表** + 已解锁的**任务**（采集/打猎/陷阱/伐木/农耕…）。
- 任务太多可以用 `Hide Mission` 隐藏（每页独立，`faction_camp.cpp:1395-1413`）。

### 3.3 蓝图建造流程（核心）

1. 切到对应方向的标签页；
2. 在蓝图列表里选一项（列表来自 `basecamp::available_upgrades(dir)`，按名称排序）；
3. 系统会检查并列出需求（材料 / 工具 / 耗时，`om_upgrade_description` → `basecamp.cpp:210`）；
4. 满足条件后派人施工（`start_upgrade` → `faction_camp.cpp:2007`）；
5. 工期到后在布告栏点"召回"，`upgrade_return` 执行 mapgen，写入 `provides`。

**硬性条件（缺一项就点不动 / 会失败）：**

| 条件 | 说明 | 代码 |
|---|---|---|
| 前提蓝图 `blueprint_requires` | 例：屠宰架需要先有熏制房 | `basecamp.cpp:314-328` |
| 未被 `blueprint_excludes` 排除 | 互斥分支，建了 A 就不能建 B | `basecamp.cpp:329-349` |
| 材料在营地范围内 | 用营地 `form_crafting_inventory()` 扫描，材料必须放在营地地面/容器内 | `basecamp.cpp:655, 738-746` |
| 工具齐备 | 同样在营地范围内可及（`_inv`） | `basecamp.cpp:354` |
| 食物储备够 | `camp_food_supply() < time_to_food(工期×人数)` 会拒绝 | `faction_camp.cpp:1968-1976` |
| 目标地块无车辆阻挡 | "perhaps there is a vehicle in the way" | `faction_camp.cpp:3572` |

**施工耗时与人力：**

```cpp
// faction_camp.cpp:1994-2002
work_days = to_workdays( making.batch_duration( player ) / result.size() );   // 按人数平摊
...
camp_food_supply( work_days * result.size() );                                // 食物按人头扣
```
- `base_camps::to_workdays`：`>11 小时`的部分按 **10 小时 = 1 个工日** 折算（`basecamp.cpp:90-98`）。
- **多派人能缩短工期，但食物总消耗基本不变**（人×天）。
- 建成后每个工人练 `construction`（`faction_camp.cpp:3584`）。

### 3.4 扩张基地（Expand Base）

流程：`MAIN` → **Expand Base** → 派人（3 小时）→ 召回时选地块 → 选类型 → 建成。
对应 `faction_camp.cpp:4122-4187`，约束如下：

| 约束 | 说明 |
|---|---|
| 解锁条件 | `can_expand()` = 中心地块 `bed` 的 provides **严格大于 方向数 × 2**（`basecamp.cpp:289-292`） |
| 距离 | 只能选**紧邻**（距离 1）的地块（`faction_camp.cpp:4135-4139`） |
| 同层 | 必须与营地同一 Z 层（`"Expansions must be on the same level as the camp"`） |
| 不重复 | 该方向已有扩张则拒绝 |
| 地形允许 | 目标地块必须能建扩张（某些地形不行，如水面） |
| 上限 | **最多 8 个扩张**（`faction_camp.cpp:1545`） |

**卡在"床位不足"怎么办**：回 `MAIN` 页把 **床/铺位** 类蓝图建起来（`bed` provides 累积），每多一个方向，需求 +2。

> 原版提示（`faction_camp.cpp:1524-1528`）：先建**农场**最稳（食物是任务燃料），其次是**锻炉**（木炭）。

### 3.5 食物与区域（升级的燃料）

- `MAIN` → **Distribute Food**：把 **营地食物区（CAMP_FOOD）** 里的食物折算成派系储备（`faction_camp.cpp:5141-5252`）。
- 必须先有 **食物区 + 营地储物区**，否则提示让你用区域管理器创建（`faction_camp.cpp:1556-1561`）。
- **储藏室（pantry）** 能提升折算率（`faction_camp.cpp:5157-5158`）：

| 剩余保质期 | 无储藏室 | 有储藏室 |
|---|---|---|
| < 2 天 | ×0.6 | ×0.7 |
| 2 ~ 5 天 | ×0.8 | ×0.85 |
| ≥ 5 天 | ×1.0 | ×1.0 |

→ **快过期的食物先建储藏室再分发**，能多榨出 10%~17%。
- 储备见底会让派系好感/尊重/信任下降（`faction_camp.cpp:5117-5122`）。

### 3.6 常见"卡住"排查表

| 现象 | 原因 / 处理 |
|---|---|
| 蓝图列表是空的 | 前提蓝图没建（`blueprint_requires`），或材料不在营地范围内 |
| 蓝图灰着点不了 | `upgrade.avail=false` → 材料/工具不齐（看描述里的红色条目） |
| "You don't have the materials for the upgrade." | 材料不在营地 `form_crafting_inventory` 视野内，搬到营地地面/箱子 |
| 食物不够派人 | 先 Distribute Food 补充储备 |
| Expand Base 灰着 | 床位不够 → 回 MAIN 建床 |
| 打猎/陷阱任务不出现 | 该方向地块没有 `hunting` / `trapping` provides → 建**屠宰架**（多数模块提供 `hunting`，如 `recipe_modular_canteen`、`fbmc_outpost`、`recipe_modular_hub` 的中央屠宰架） |
| 同伴召不回来 | 外出 **未满 24 小时**不能用紧急召回（`faction_camp.cpp:1616-1618`） |
| 建成后没反应 | 目标地块有车辆挡住 mapgen，挪车重来 |

## 5. 一页纸操作清单

1. **先有吃的**：MAIN → Distribute Food（建好食物区 + 储物区）；有余力建 pantry。
2. **解锁打猎**：在中心或食堂类扩张里建 **屠宰架（butchery rack）** → 解锁 `hunting`。
3. **挑人**：枪法最高、感知次高、生存或口才 ≥5 的那个去打猎（1 人）。
4. **保底**：同时开 **陷阱**（2 人），判定次数是打猎的 4 倍且成功率更高。
5. **回来立刻处理**：好刀 + 高生存技能 + 完整流程屠宰，肉当天熏/腌/冻。
6. **升级**：布告栏 → 目标方向页 → 攒齐材料工具 → 多人施工 → 召回。
7. **扩张**：床位够（> 方向数×2）→ Expand Base → 优先农场，其次锻炉。
