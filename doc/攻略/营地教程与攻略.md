## 第 0 章 · 速览

| 问题 | 答案 |
|---|---|
| 营地到底是什么？ | 一个 overmap 地块（中心）+ 最多 8 个相邻地块（扩张）的**同伴任务调度系统**。 |
| 最小启动成本？ | **1 个同伴 + 一块能建的地 + 一堆食物**。不需要任何建材。 |
| 就算不发展也值得建吗？ | **值得**。营地会**自动喂饱 2 格内的同伴**，光这一条就省掉大量微操。 |
| 营地用什么结算？ | 一个抽象的 **kcal 储备**（`food_supply`）。食物 → 储备 → 付给外出同伴当工钱。 |
| 同伴一天吃多少？ | **2500 kcal/人/天**（`faction_camp.cpp:5135-5138`）。 |
| 怎么扩张？ | 中心地块 `bed` 数量 **> 已有扩张数 × 2**（`basecamp.cpp:289-292`）。 |
| 最大规模？ | 中心 + **8 个扩张地块**，每个扩张有自己的蓝图树和任务。 |
| 主要坑？ | ① 材料必须放在营地范围内；② 食物不够会拒绝派人；③ 召回后肉会烂；④ 目标地块有车会建不了。 |

# 第一部分 · 教程篇：从零到营地能跑起来

## 1.1 营地能给你什么

营地不是一个"建筑系统"，它是**同伴劳动力的管理界面**。建好之后你能得到三样东西：

1. **自动供养** —— 同伴饿了会自己从营地储备里吃，渴了会去井里喝（需要水井）。你在营地 2 个 overmap 地块范围内就不用管饭了。
2. **后台任务** —— 派人出去采集、打猎、陷阱、觅食、伐木、农耕、侦察、巡逻，到时间再召回收成果。期间这个同伴从地图上消失，不占你的视野、不拖慢你的节奏。
3. **批量制造** —— 建了锻炉/厨房/工坊后，同伴能用营地的"假物品"（`fake_forge`、`fake_woodstove` 等，见 `data/json/items/basecamp.json`）批量做东西，包括你自己做起来很慢的木炭、盐、熏肉。

**营地不会给你的**：它不会自动战斗防守，不会自动修墙，不会替你屠宰（打猎带回来的是**整具尸体**，得你自己动手）。

## 1.2 开工三件套

### ① 至少 1 个同伴

营地必须由**同伴（follower）**来开 —— 对话选项挂在同伴身上，不是你自己能做的事。

```
对同伴按 C 交谈 → 关于阵营营地 → "I want you to build a camp here."
```

（入口：`data/json/npcs/TALK_FACTION_CAMP.json:18`，`data/json/npcs/common_chat/TALK_COMMON_ALLY.json:1010`，效果 `start_camp` → `src/faction_camp.cpp:669`）

- 该同伴必须**站在你想建营地的那个 overmap 地块上**（条件 `npc_at_om_location: FACTION_CAMP_START`）。
- 站错地方会走另一条分支：*"Since we can't build a camp here, where can we build a camp?"* → 会列出所有可用地点，很好用，**不确定哪里能建就先问这一句**。
- 不需要同伴有什么技能水平，任何跟班都行。

### ② 一块能建的地

| 营地类型 | 可建地形 | 特点 |
|---|---|---|
| **Bare Bones（骨架营地）** | **任何地方** | 最灵活。不强制任何建造，布告栏要你自己造。所有扩张直接解锁（但仍需地形合适）。 |
| **Modular Field Camp v1 / v2** | `field`（**真·空地**，不是农场/牧场那种） | 从零起家，最耗资源，但扩张空间最大。v2 无战壕、床位更多、扩张不依赖床位。 |
| **Evac Shelter** | 各类疏散中心 | 开局快，周围常有空地可扩张。 |
| **Fire Station** | `fire_station` | 砖房 + 金属门，安全性最好。**不能扩张**。 |
| **Lighthouse / Helipad / Radio Tower** | 对应建筑 | 自带净水 + 厨房，可补地窖/屠宰架/无线电塔。 |
| **Military Outpost** | `outpost` / `outpost_cross` | normal 版 2 床（1 扩张），cross 版 4 床（2 扩张）。 |
| **Pottery Cottage / Light Industry / Mansion / Fire Lookout / Sealab** | 对应建筑 | 各有专属蓝图与专属扩张。 |

（完整表见 `data/json/recipes/basecamps/recipe_groups.json`，游戏内问同伴 "where can we build a camp" 也会列。）

> **注意**：modular 空地营地和骨架营地同时可用时，会弹列表让你选版本。v2 明显更省心（不挖战壕、床更多、扩张不受床位卡），**能选 v2 就选 v2**。

### ③ 三个区域（Zone）

营地靠区域识别"哪些东西算营地的"。按 `Y` 打开区域管理器：

| 区域类型 | 用途 | 不建会怎样 |
|---|---|---|
| **CAMP_FOOD** | 放"准备充公"的食物 | Distribute Food 直接报错中止（`faction_camp.cpp:5143-5146`） |
| **CAMP_STORAGE** | 营地储物区，建造材料的扫描范围、赃物倾倒点 | 拿不到材料、无法分发食物 |
| **LOOT_UNSORTED** | 未分拣赃物区 | 杂务任务（Menial Labor）没东西可分拣 |

打开布告栏时如果没有这些区域，游戏会提示你用区域管理器创建（`faction_camp.cpp:4881`）。

## 1.3 第一步：开营地

```
1. 带一个同伴走到目标地块
2. C → 关于阵营营地 → "I want you to build a camp here."
3. （若有多套方案）在弹出的列表里选营地类型/版本
4. 同伴立刻勘测完毕，地块在大地图上变成 faction_base_*
5. 除 Bare Bones 外，同伴会自动造好一块布告栏
```

**三个会让你失败的硬条件**（`faction_camp.cpp:669-711`）：

| 条件 | 报错 |
|---|---|
| 该地形没有可用营地类型 | *"You cannot build a camp here."* |
| 附近（3 格内）已有别的 faction_base 地块 | *"You are too close to another camp!"* |
| 地块上有车挡住 mapgen | *"...failed to start the ... basecamp, perhaps there is a vehicle in the way."* |

**Bare Bones 例外**：它不会自动造布告栏，你要自己在营地里**手工造一块**：
`*` 建造菜单 → FURN → 布告板（2x4 ×4 + 钉子 ×8，需 HAMMER 2 / SAW_W 1，20 分钟）——`data/json/construction.json:2052-2063`。造好后 `e` 检视它即可。

## 1.4 第二步：认识布告栏

`e` 检视布告栏（或和驻场同伴说 *"Show me what needs to be done at the camp."*）打开营地管理器。

顶部标签页（`basecamp.cpp:47-58`）：

```
MAIN | [N] [NE] [E] [SE] [S] [SW] [W] [NW]
 ↑                    ↑
中心地块            8 个扩张地块，每块一个页签
```

**MAIN 页独有**：

| 条目 | 作用 |
|---|---|
| **Distribute Food** | 把 CAMP_FOOD 区里的食物折算成 kcal 储备 |
| **Expand Base** | 扩张（灰着 = 床位不够） |
| **Assign Jobs** | 给驻场同伴设岗位优先级 |
| **Assign Workers** | 指定哪些同伴归属这个营地 |
| **Abandon** | 放弃营地 |
| **Emergency Recall** | 紧急召回（有同伴在外时才出现） |

> 用 **Tab** 键切页。任务太多可以用 *Hide Mission* 隐藏，每页独立记忆（`faction_camp.cpp:1395-1413`）。

**无线电远程**：你和同伴各带一个双向无线电，就能隔着地图用无线电开营地菜单（`by_radio`）。此时 Distribute Food / Assign 类操作不可用（`faction_camp.cpp:1566`），但派任务可以。

## 1.5 第三步：让营地有饭吃

这是**唯一必须学会的循环**，营地所有活动都靠它驱动。

```
把食物丢进 CAMP_FOOD 区  →  MAIN → Distribute Food  →  食物消失，变成 kcal 储备
```

**折算规则**（`faction_camp.cpp:5160-5200`）：

| 条件 | 折算 |
|---|---|
| 已腐烂 / 不可食用 / `INEDIBLE` | **0%**（直接不算） |
| 适口性（fun）**< -6** | **0%**（屠宰下脚料之类） |
| 剩余保质期 < 2 天 | **60%**（有储藏室 **70%**） |
| 2 ~ 5 天 | **80%**（有储藏室 **85%**） |
| ≥ 5 天 | **100%** |

- 密封容器（spoil_multiplier = 0）里的食物按 **100%** 算。**罐头/真空包装优先充公**，散装鲜货自己吃。
- **储藏室（pantry）**能把临期食物的折损从 40% 拉到 30%。快过期的食物**先建储藏室再分发**，能多榨 10%~17%。

**消耗规则**：

```
1 名同伴 1 天 = 2500 kcal   （≈104 kcal/小时）
派出时先扣 6 小时的粮（625 kcal），召回时补扣剩余时长
储备不足 → 直接拒绝派人（faction_camp.cpp:1920）
同伴回来发现没粮 → 好感/尊重/信任下降（faction_camp.cpp:5117-5122）
```

**水**（`basecamp.cpp:294-298`）：建了水井（`water_well` / `fbmh_well_north` / `faction_base_camp_12` 等）之后，附近同伴渴了会自己去喝。官方建议：**能建井就尽早建**（`TALK_CAMP_TUTORIAL_ADVICE`）。

## 1.6 第四步：派第一个任务

所有营地任务都是同一个三步循环：

```
① 在对应方向页选中任务 → 回车派出（同伴消失，开始计时）
② 等/去干别的
③ 时间到了，同一条目变成 "[方向] Recover XXX" → 再次回车召回，成果结算
```

- 标着 **Repeated** 的任务（采集/拾柴/觅食/陷阱/打猎）**不召回就一直干**，判定随时间累积，召回时一次性结算。
- 召回时产物会**堆到营地的倾倒点**（dumping spot，即 CAMP_STORAGE 区最近的格子）—— **别把倾倒点堆满**。
- **紧急召回**（Emergency Recall）：取消任务并立刻拉人回来，**所有投入作废**。且同伴外出**未满 24 小时不可用**（`faction_camp.cpp:1616-1618`）。只在人卡住了才用。

## 1.7 第五步：扩张

```
MAIN → Expand Base → 派人（勘测 3 小时）→ 召回时选方向 → 选类型 → 建成
```

**解锁条件**（`basecamp.cpp:289-292`）：

```
中心地块的 bed 提供量  >  已有扩张数 × 2
```

即：第 1 个扩张要 ≥3 床，第 2 个要 ≥5 床，第 3 个 ≥7 床…… 卡住了就回 MAIN 页**继续造床**。
（Modular Field Camp **v2** 和 Bare Bones、Mansion 不受这条限制，可以直接勘测全部扩张。）

**其余约束**（`faction_camp.cpp:4122-4187`）：必须与中心**紧邻**（距离 1）、**同一 Z 层**、该方向尚无扩张、地形允许，**最多 8 个**。

### 通用扩张地块一览

| 扩张 | 作用 | 推荐度 |
|---|---|---|
| **Farm（农场）** | 整格耕地，可派任务犁地/播种/收获 | ★★★★★ 第一优先，食物是任务燃料 |
| **Canteen（食堂）** | 扩展厨房 + 餐区 + 储藏室，解锁大量烹饪配方 | ★★★★★ pantry 折算加成在这 |
| **Fabrication Workshop（工坊）** | 大型制造区，同伴能用设备快速造东西 | ★★★★☆ 产出建造材料 |
| **Garage（车库）** | 大空间，可放车/拆车 | ★★☆☆☆ 主要为停车 |
| **Livestock Area（畜栏）** | 养牛/马/鸡（**动物要你自己弄来**） | ★★☆☆☆ 中后期 |
| **Central Storage（仓库）** | 大容量存储，v2 可建高容量储物家具 | ★★☆☆☆ 中后期 |
| **Saltworks（盐场）** | 产盐，腌制保鲜的关键原料 | ★★★☆☆ 配合熏制房 |

> 每种扩张大多有 **v1 / v2 两个版本**，建造前看清楚描述再选（例如 Storehouse v2 建议只放在 N/E/S/W 四个正方向）。

## 1.8 人事管理

**Assign Workers（分配工人）**：指定哪些同伴归属这个营地。只有归属了这个营地的人，才会出现在任务派人的候选名单里，也才会被算作"驻场"。

**Assign Jobs（分配岗位）**：给驻场同伴设**活动优先级**。选中一个人 → 给各类活动（搬运分拣、木工、觅食等）设 0~N 的优先级，**0 = 不做**。同伴在闲置时会按优先级自动去做这些活儿（`faction_camp.cpp:2231-2360`）。

- 这是让营地"自己转起来"的关键：**把分拣（menial）和觅食（forage）设上优先级，营地就会自动整理赃物、自动补货。**
- 岗位是**活动**级别的，不是任务级别的 —— 它对应的是同伴的自动行为，和布告栏里的一次性任务不冲突。

## 2.1 provides 标签速查表

| provides | 解锁什么 | 怎么获得 |
|---|---|---|
| `bed` | 每 2 点允许 1 个扩张 | 造床/宿舍类蓝图 |
| `gathering` | 采集物资、分发食物、重置分拣点 | 中心地块早期蓝图 |
| `firewood` | 拾柴 | 早期蓝图 |

| `farming` | 犁地 / 播种 / 收获 | 农场扩张 |
| `recruiting` | 招募同伴 | 中央指挥建筑 / 办公室 |

> **排查口诀**：任务没出现 = 缺 provides = 去对应方向的蓝图列表里找"名字里带这个功能"的建筑。

## 2.3 判定次数表（决定产出的真正变量）

```
attempts = checks_per_cycle × 实际外出时长 / min_time
```

| 任务 | checks_per_cycle | min_time | **单人 24h 判定次数** |
|---|---|---|---|
| 采集物资 | 6 | 3h | **48** |
| 拾柴 | 6 | 3h | **48** |
| 觅食 | 12 | 4h | **72** |
| 陷阱 | 4 | 6h | 16 |
| 打猎 | 2 | 6h | 8 |

**单次成功率**：

| 任务组 | 判定 | 成功率 |
|---|---|---|
| 采集 / 拾柴 / 觅食 | `skill > rng(0, 15)` | min(skill, 16) / **16** |
| 陷阱 / 打猎 | `skill > rng(0, 30)` | min(skill, 31) / **31** |

> **这张表是整个营地攻略的核心**。采集类任务的难度只有 15，而技能公式是 `2×生存 + 感知` —— 生存 4、感知 8 就达到 16，**每次判定必成功**。之后产出只由**判定次数×人数**决定，与技能无关。
> 打猎/陷阱的难度是 30，技能很难顶满，成功率长期是瓶颈。

# 第三部分 · 攻略篇

## 3.1 食物经济学

营地的一切都是 **kcal 进 / kcal 出**：

```
收入：分发食物   /   觅食·采集·农耕的实物产出（再分发）
支出：2500 kcal × 同伴数 × 外出天数   +   建造时 人×工日 × 2500 kcal
```

**要点**：

1. **先建营地，再谈发展。** 官方原话：*"it's a good idea to establish a minimal camp anywhere you intend to be for a while."* 一个只挂着 CAMP_FOOD 区的空壳营地，就能让你完全不用管同伴吃饭。
2. **临期食物是营地的最佳燃料。** 反正自己吃不完要烂，充公还能拿 60%~85%。**永远先充公临期的，新鲜的自留。**
3. **食物不够会连锁崩盘**：拒绝派人 → 没法采集 → 更没食物。卡住时先 Distribute Food。
4. **建造不省粮**：`work_days = 工期 / 人数`，食物扣 `work_days × 人数`（`faction_camp.cpp:1994-2002`）。**加人只省时间，不省粮。** 缺粮时反而应该少派人。

## 3.2 采集 vs 觅食 vs 陷阱 vs 打猎（修正版）

> ⚠️ 早期笔记里"陷阱比打猎划算"的说法**不准确**，这里给出修正后的完整排序。

### 期望产出（单人 24 小时）

| 任务 | 判定次数 | 典型成功率 | 期望次数×成功率 | 单次期望热量 | **净 kcal/天** |
|---|---|---|---|---|---|
| **觅食** | 72 | 生存5/感知10 → skill 20 → 100% | 72 | 野生蔬果（少量） | 稳定但低热量，胜在**免费且不占工具** |
| **采集物资** | 48 | 同上 → 100% | 48 | 建材为主 | 建造材料的**主力来源** |
| **陷阱**（2 人） | 16×2 = 32 | 陷阱3/感知10 → skill 16 → 52% | 16.5 具 | **~635 kcal/具** | ≈ 10,500 − 5,000（2 人口粮）= **~5,500** |
| **打猎**（1 人） | 8 | 枪法3/感知10 → skill 9 → 29% | 2.3 具 | **~4,995 kcal/具** | ≈ 11,600 − 2,500（1 人口粮）= **~9,100** |

（热量为按屠宰产出折算的估算值；陷阱中位 ~305 kcal/具，打猎中位 ~1,064 kcal/具）

### 结论：三条线各干各的，别互相替代

| 线 | 定位 | 为什么 |
|---|---|---|
| **采集 + 拾柴** | **建造燃料线** | 唯一能把建材稳定搬回家的途径。难度低、次数多，生存够就必成。 |
| **觅食** | **零成本保底口粮** | 难度同样低、次数最多（72/人天），不看运气不看装备。**前期真正的口粮主力。** |
| **陷阱** | **稳定肉源 + 自我成长** | 训练组 `trapping` 给 devices 权重 80，**每次派出去都会涨陷阱技能 → 成功率自己变高**。风险 1/15。 |
| **打猎** | **高方差爆发** | 期望被牛/驼鹿/熊这类权重 1 的稀有大型猎物拉爆，**一半以上期望来自 5% 的概率**。中位只有 ~1,000 kcal，大部分时候带回的是狐狸和鸭子。 |

### 打猎的两个坑（必读）

1. **打猎练不出枪法。** 打猎的判定技能是 `gun`（枪法），但结算时训练的技能组是 `hunting`，映射到 archery/rifle/pistol/shotgun/smg 等，**不含 gun**（`data/json/skills.json`）。所以反复派人打猎，**成功率永远停在初始值**。想提高只能换人（或改代码）。
2. **枪法不保命。** 遭遇战判定用的是**生存**（逃跑）和**口才**（交涉），前两项失败才进战斗判定，失败即**同伴死亡**（`faction_camp.cpp:5445-5495`）。打猎 `danger = 10`，即**每次召回 1/10 概率触发**。
   → **派生存 ≥5 或口才 ≥5 的去打猎，比派枪法高的更重要。**

### 陷阱的独特价值

- 训练组 `trapping` 权重：**陷阱 80 / 生存 15 / 制造 10 / 游泳 5 / 弓术 5 / 近战 5**。派出去跑几趟，陷阱技能就上去了，成功率**自我强化**。
- 风险 1/15，比打猎安全 50%；方差小，不会出现"三天带回三只鸭子"。
- 缺点：只有小型猎物，屠宰受技能影响很小（`base_num` 类条目走整数 roll，不乘产出系数），产出上限低。

## 3.3 屠宰与保鲜：真正的瓶颈

打猎/陷阱带回的是**尸体不是肉**，从尸体到食物还有两步，全在玩家自己身上：

**① 屠宰产出系数**（`activity_handlers.cpp:794-802`）：

```
yield = 0.5 × clamp(生存/10, 0, 1) + 0.3 × clamp((工具品质+50)/100, 0, 1) + 0.2 × clamp(敏捷/20, 0, 1)
```

| 配置 | 产出系数 |
|---|---|
| 生存 0、敏捷 8、无工具 | **0.34** |
| 生存 10、敏捷 12、好刀 | **0.68** |

**差距接近 2 倍** —— 这是玩家侧最大的可控杠杆。

- 用 `BUTCHER` 品质高的刀（切肉刀 / 屠刀 > 小刀）。
- 走完整流程：放血 → 剥皮 → 开膛 → 分割。**不要用"快速屠宰"**，肉量 `/4`。
- 流程损耗：开膛 −25%、剥皮 −15%、尸体被打烂（GIBBED）再 −15%。
- **只有定义了 `mass_ratio` 的条目才乘这个系数**；小鼠/花栗鼠这类小猎物走 `base_num + butchery×scale`，受生存影响很小（`activity_handlers.cpp:885-1027`）。

**② 保鲜**：生肉 `spoils_in: 1 day`。一堆肉一天就烂 —— **熏制 / 腌制 / 冷冻必须跟上**。营地里对应的是**熏制房（smoking）**、**储藏室（pantry）**、**盐场（saltworks，供腌制用盐）**。

> **实操顺序**：同伴带回尸体 → 你立刻屠宰 → 当天熏/腌 → 剩下的充公换 kcal。拖一天就全烂。

## 3.4 建造：怎么不卡住

营地建造 = 布告栏里的蓝图列表，本质是带 `construction_blueprint` 字段的特殊配方（`data/json/recipes/basecamps/**`）。

**流程**：选方向页 → 选蓝图 → 看需求 → 凑齐材料工具 → 派人 → **召回时才真正改地图**。

**硬性条件**（缺一项就点不动）：

| 条件 | 说明 |
|---|---|
| `blueprint_requires` | 前置 provides（例：屠宰架需要先有熏制房） |
| `blueprint_excludes` | 互斥分支，建了 A 就不能建 B |
| 材料 | **必须在营地范围内**（`form_crafting_inventory()` 扫描营地地面与容器）。放在隔壁房间不算。 |
| 工具 | 同样要在营地范围内可及 |
| 食物 | 储备 < 工期 × 人数 × 2500 会拒绝 |
| 车辆 | 目标地块有车会失败（*"perhaps there is a vehicle in the way"*） |

**工期与人力**（`faction_camp.cpp:1943-2050`）：

```
work_days = to_workdays( 配方时长 / 人数 )     // >11 小时的部分按 10 小时 = 1 工日 折算
食物消耗 = work_days × 人数
```

- **多人施工只省时间，不省粮**（人×天恒定）。
- 建成后每个工人涨 `construction`。
- 派遣阶段地图**不会变化**，只有召回那一刻才 mapgen。所以召回前把车挪开还来得及。

## 3.5 扩张顺序推荐路线

官方建议（`TALK_CAMP_TUTORIAL_ADVICE`）：**农场 → 食堂/工坊 → 其他**；畜栏、仓库、盐场不建议当第一个。

结合上面的数值，推荐这条线：

```
① 空壳营地（只为自动喂饱）——立刻建，任何地方都行
        ↓
② 攒床位 → 第 1 个扩张 = 农场（食物自给，犁/播/收可派任务，完全不耗运气）
        ↓
③ 中心地块：屠宰架（解锁打猎+陷阱）→ 熏制房 → 储藏室（pantry）
        ↓
④ 第 2 个扩张 = 食堂（大量烹饪配方 + 井 + 地窖）
        ↓
⑤ 第 3 个扩张 = 工坊（造建材，反哺建造）
        ↓
⑥ 中心：水井 → 无线电塔（招募范围）→ 围墙工事
        ↓
⑦ 畜栏 / 仓库 / 盐场 / 第二座农场
```

**每一步的判断标准**：

- 卡在"Expand Base 灰着" → 回 MAIN 页造床。
- 卡在"蓝图列表空/灰" → 缺前置 provides 或材料不在营地范围内。
- 卡在"食物不够" → 先建农场/食堂，或者先跑几轮采集觅食。

## 3.6 招募同伴

营地招募（`faction_camp.cpp:3967-4078`）需要 `recruiting` provides（中央指挥建筑/办公室），一次 4 天，同时只能派 1 人。

**三道判定**：

| 步骤 | 公式 |
|---|---|
| ① 找到人 | `rng(1,20) + 生存 > 17` |
| ② 说服跟回 | `rng(1,20) + 社交 > 19` |
| ③ 报价 | `rng(1,20) + appeal ≥ 10`，`appeal = rng(-5,3) + min(社交/3, 3)` |

**最大杠杆**：第 ③ 步的谈判窗口里，每点一次 *"Increase Food"* = **appeal +1 = +5%**，而且**失败不扣粮**（只在成功时才扣，`faction_camp.cpp:4069`）。
→ **每次都把显示的成功率拉到 100% 再 Make Offer。**

**两个已知问题**（维护者注意）：

1. **营地吸引力评分实际无效**：`sbase = cur_level × 5`，新营地 `cur_level = -1` → −5，三项加满上限约 63 < 100，导致 `floor((100×speech + score)/100)` 恒等于 `speech`，score 贡献为 0。UI 里显示的 Base/Expansion/Faction/Special **全是摆设**。疑似括号写错，应为 `speech × (100+score) / 100`（`faction_camp.cpp:3989`）。
2. **派人有误导**：派人菜单按**枪法**排序并显示枪法（`faction_camp.cpp:1869`），但判定用的是生存和社交。**按枪法选人是错的。**

## 3.7 风险与死亡

只有采集类（采集/拾柴/觅食/陷阱/打猎）有遭遇战判定，其余任务无风险。

```
每次召回：one_in(danger) 触发遭遇战
  danger:  采集 20 / 拾柴 20 / 觅食 15 / 陷阱 15 / 打猎 10
```

遭遇战三连判定（`faction_camp.cpp:5445-5495`）：

1. `生存 + favor > rng(0,10)` → 溜走，练 gathering
2. `口才 + favor > rng(0,10)` → 遇到友好路人，练 recruiting
3. 都不行 → 战斗：`(近战 + 0.5×生存 + 钝 + 斩 + 刺 + 徒手 + 闪避) × rng(8,12) > 怪物数 × rng(8,12)`
4. **失败 = 同伴死亡**，尸体留在原地，从 overmap 移除

`favor`：采集 +2、陷阱 +1、打猎 0。

**保命口诀**：外出任务一律**优先派生存高的**，其次口才。战斗巡逻（danger 极高）是唯一"故意去打"的任务，派它之前想清楚人要不要得回来。

# 第四部分 · 排错与清单

## 4.1 常见"卡住"排查表

| 现象 | 原因 / 处理 |
|---|---|
| *"You cannot build a camp here."* | 地形不支持。问同伴 "where can we build a camp" 看列表 |
| *"You are too close to another camp!"* | 3 格内已有 faction_base 地块 |
| 建营地/建造失败，提到 vehicle | 目标地块有车，挪走再来 |
| *"This bulletin board is not inside a camp"* | 布告栏不在营地地块内（Bare Bones 常犯） |
| 布告栏打不开任务列表 | 同伴没归属营地 → Assign Workers |
| Distribute Food 报错中止 | 缺 CAMP_FOOD 或 CAMP_STORAGE 区域 |
| 蓝图列表是空的 | 缺前置 provides，或该方向地块不支持 |
| 蓝图灰着点不了 | 材料/工具不齐，看描述里的红色条目 |
| *"You don't have the materials for the upgrade."* | 材料**不在营地范围内**，搬到营地地面/箱子 |
| 食物不够派人 | 先 Distribute Food；临期食物优先充公 |
| Expand Base 灰着 | 床位不够（bed > 扩张数×2），回 MAIN 造床 |
| 打猎/陷阱任务不出现 | 该方向没有 `hunting`/`trapping` provides → 建**屠宰架** |
| 同伴召不回来 | 外出**未满 24 小时**不能用紧急召回 |
| 建成后地图没变化 | 有车挡住 mapgen，挪车重新召回 |
| 分发的 kcal 比预期少 | 临期食物折损；建储藏室能补救 |
| 打猎总带回小动物 | 正常。中位产出只有 ~1,000 kcal，别指望它 |

## 4.2 开局 30 天时间表

| 阶段 | 目标 | 产出 |
|---|---|---|
| **Day 1** | 带 1 个同伴，在落脚点开**骨架营地** | 同伴自动吃饭，不再微操 |
| **Day 1-2** | 划 CAMP_FOOD + CAMP_STORAGE 区，充公第一批临期食物 | 储备起步 |
| **Day 3-7** | 建造蓝图：床 ×N → 屠宰架 → 熏制房；同时派人跑采集/拾柴 | 建材囤积，解锁打猎陷阱 |
| **Day 7-14** | 床位够 → 第 1 个扩张 = **农场**；中心建储藏室 | 食物自给，折算率提升 |
| **Day 14-21** | 建水井；派人长期跑觅食 + 陷阱 | 稳定口粮；陷阱技能自我成长 |
| **Day 21-30** | 第 2 个扩张 = 食堂；打猎作为补充（派生存高的人） | 完整食物链闭环 |

## 4.3 一页纸清单

```
【启动】
□ 1 个同伴站到目标地块 → 对话 → 建营地
□ 划 CAMP_FOOD 区 + CAMP_STORAGE 区
□ 造布告栏（仅 Bare Bones 需要）
□ 充公临期食物 → Distribute Food

【日常循环】
□ 派人：采集×3 / 拾柴×3 / 觅食×3（长驻，Repeated）
□ 派人：陷阱×2（长驻，技能会自己涨）
□ 打猎×1（选生存或口才 ≥5 的人，别看枪法）
□ 定期召回 → 屠宰（好刀 + 高生存）→ 熏/腌 → 剩余充公

【发展】
□ 造床 → 床位够就 Expand Base
□ 扩张顺序：农场 → 食堂 → 工坊 → 其他
□ 中心：屠宰架 → 熏制房 → 储藏室 → 水井 → 无线电塔 → 围墙
□ 驻场同伴设岗位优先级（分拣 + 觅食）

【红线】
□ 建造材料必须放在营地范围内
□ 建造前挪走目标地块的车
□ 紧急召回只在人卡住时用（24 小时后可用，投入全废）
□ 外出任务派生存高的，不是枪法高的
```
